<objective>
Add the SNB (Swiss National Bank) policy-rate data path: a stitching fetcher that handles the 2019-06 series cutover, a Supabase cache layer for the `snb_rates` table, a one-shot bulk seed script, and a quarterly Vercel cron route. This is the **only** new external data integration in Phase 5.

Purpose: The backtest engine's Sharpe metric (D-19) requires a point-in-time CHF risk-free rate. SNB's `LZ` policy rate only exists from 2019-06 onward; older history uses the midpoint of the SNB Libor target range (`UG0`, `OG0`). Both sources must be stitched and persisted so the batch endpoint (Plan 04) can return them with a single range query.

Output: Two new pipeline modules, one cron route, one seed script, one new npm script in `package.json`.
</objective>
