useBacktestWorker hook contract (consumed by Plan 06 UI):
```typescript
export function useBacktestWorker(): {
  run: (input: BacktestInput) => Promise<{ result: BacktestOutput; inputsHash: string }>
  terminate: () => void
  isRunning: boolean
}
```
The hook manages worker lifecycle (mount → new Worker, unmount → terminate), serializes one in-flight run at a time (rejects subsequent calls or queues — implementer picks), and returns a Promise that resolves with the WorkerResponse.done shape.

- import { createChart, LineSeries, AreaSeries, HistogramSeries } from 'lightweight-charts'
- chart.addSeries(LineSeries, opts) — NOT chart.addLineSeries() (v4 API removed)

- subscribeCrosshairMove for tooltip
- ResizeObserver for width tracking
- chart.remove() in cleanup

Worker → main thread RPC (per RESEARCH Pattern 1):
- Main thread sends WorkerRequest { kind: 'run', payload: BacktestInput }
- Worker responds with WorkerResponse { kind: 'done', result, inputsHash } OR { kind: 'error', error }
- One in-flight call at a time; hook tracks promise resolvers
